# Cix Build System brand assets

`cix-cbs-logo.svg` is the canonical documentation-facing logo. It preserves
the approved raster artwork at its native 1001×276 dimensions through a
relative image reference; this keeps the logo visually exact while providing
an SVG container for documentation and web embedding.

`cix-cbs-logo.png` is the source artwork used by the SVG wrapper. Keep the two
files together and do not redraw or recolor the mark without a documented brand
decision.
