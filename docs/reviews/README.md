# Validation records

One record per closed issue, written when that issue closed. Each states the
decision taken, the evidence for it, and the acceptance criteria met.

**These are history, not status.** A record describes the implementation as it
stood at its close date and may over-claim scope relative to today; several
have been superseded by later work. The issue tracker is the authority on open
work, and [repository status](../repository-status.md) on what this repository
owns now. The absence of a record does not mean an issue is open — some closed
without one.
